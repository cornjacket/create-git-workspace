# genesis — the effort that built this generator

Archived plan. [`PLAN.md`](PLAN.md) is the sequence and the outcome; the
`NNN-slug.md` files beside it are its task breakdown, one per task, in build
order.

These were the live tracker while the work was happening (they lived in a
top-level `tasks/` directory). They are kept for the *why* — each records its
acceptance criteria, what actually landed, and the decisions and dead ends along
the way. The durable conclusions have graduated into
[`DESIGN.md`](../../../DESIGN.md); read that first, and come here when you want
the history behind a line of it.

Status legend used in the files: `todo` · `in-progress` · `blocked` · `done`.

Nothing here is live. New work starts with a new `PLAN.md` at the repo root —
see [`../README.md`](../README.md) for the workflow.
